# Carpschool Native Android Client

Native Android application built with **Kotlin** and **Jetpack Compose** (Material Design 3) for the Carpschool federated campus ridesharing network.

---

## Tech Stack

- **UI**: Jetpack Compose + Material Design 3
- **Navigation**: Jetpack Navigation Compose
- **Maps**: Google Maps Compose SDK (`com.google.maps.android:maps-compose`)
- **Networking**: Retrofit 2 + OkHttp
- **WebSockets**: `socket.io-client-java`
- **Location**: `FusedLocationProviderClient` for single discrete GPS snapshots at boarding and dropoff

---

## Building & Running

Open this folder in Android Studio (Ladybug or newer) and sync Gradle.
